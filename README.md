# TutorIS

Учебный проект по дисциплине «Проектирование информационных систем».
Тема: **информационная система организации работы частных репетиторов**.
Решение рассчитано на множество независимых преподавателей с раздельными данными.

## Воспроизведение

Пересчёт чисел, без внешних библиотек:

```bash
python3 lab1/calculations/calculate.py
```

Перестроение исходников и SVG диаграмм:

```bash
python3 lab1/tools/generate_diagrams.py
```

PDF диаграмм экспортируются из соответствующих `.drawio` в draw.io Desktop. Версия `report.pdf` создаётся скриптом `lab1/tools/render_report.py`: нужны `reportlab`, `pypdfium2` и шрифты Arial (в скрипте указан системный путь macOS). Проверка связей, чисел и комплекта:

```bash
python3 lab1/tools/verify.py
```
